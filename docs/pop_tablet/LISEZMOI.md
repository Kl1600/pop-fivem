# POP Tablet — dossier de planification

Ce dossier contient toute la planification de la nouvelle tablette (repartie de zéro) :
specs/ (fiches des fonctionnalités), tech/ (choix techniques), design/ (jetons, maquette.html, captures),
plan/ (plan en 48 sessions avec les prompts), idees/ (banque d'idées).

**Correspondance des chemins** : dans les prompts du plan, tout chemin
`/mnt/project-files/pop_tablet/...` correspond désormais à `docs/pop_tablet/...` dans ce dépôt.
Exemple : `/mnt/project-files/pop_tablet/specs/01-base.md` → `docs/pop_tablet/specs/01-base.md`.

Point de départ : `plan/30-plan-sessions.md`, session 01.
